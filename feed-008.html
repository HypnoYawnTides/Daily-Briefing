DeepSeek V4：接近前沿，价格只是零头——开放模型的效率跃迁
Simon Willison 报道了 DeepSeek V4 系列：V4-Pro 1.6T 参数（目前最大开放权重模型），V4-Flash 284B 参数，均为 MoE 架构、支持 100 万 token 上下文、MIT 开源。核心冲击在定价——V4-Flash $0.14/百万输入 token，比 GPT-5.4 Nano 还便宜。效率突破惊人：在 100 万 token 场景下，V4-Pro 单 token 浮点运算量仅为 V3.2 的 27%，KV 缓存大小仅 10%。DeepSeek 自己承认落后最前沿 3-6 个月，但"接近前沿 + 价格是零头"的组合对闭源定价构成直接压力。对 PM：模型选型不再是"谁的 benchmark 高"，而是"你愿意为最后 3-6 个月的性能差距付多少倍溢价"。

Claude Code 定价风波：$20 → $100 测试引发信任危机
Simon Willison 详细记录了 Anthropic 4 月 22 日悄然更新定价页面——Claude Code 从 $20/月 Pro 计划移除，仅在 $100+ Max 计划可用。社区迅速反弹，Anthropic 增长负责人称是"面向 2% 新注册用户的测试"，但所有人都能看到更新后的页面。Simon 批评了三点：信任损害（一条推文不是传达定价变更的方式）、可及性（他拒绝围绕 $100/月工具做教学）、竞争机会（OpenAI Codex 趁机强调免费层级）。Anthropic 最终撤回了页面变更，但 2% 实验仍在继续。对 PM：定价测试不只是增长实验，它是信任信号——被发现的"测试"和正式变更造成的信任损害一样大。
