模型公司下场做垂直：Anthropic 的行业交付转型

From selling APIs to delivering industry solutions — Anthropic goes vertical.
Daily 009 2026-05-06 2 Sources 4 Min Read
一周内两个动作——10 个金融 agent 模板把"通用模型"变成"行业解决方案"，联合 Blackstone/Goldman/HF 成立企业 AI 服务公司直接做中型企业的系统集成。Anthropic 正在走一条与 OpenAI（消费端产品）和 Google（基础设施）不同的路——向下游走、做垂直交付。
AN Finance Agents · Anthropic AN Enterprise AI Co. · Anthropic
§ 01

Templates.10 个金融 Agent 模板：从 API 到行业方案的跳跃

5 月 5 日发布的 10 个 agent 模板覆盖了金融服务的两大高成本领域：研究/客户覆盖（Pitch builder、Meeting preparer、Earnings reviewer、Model builder、Market researcher）和财务/运营（Valuation reviewer、GL reconciler、Month-end closer、Statement auditor、KYC screener）。↗ News

这些不是概念验证——它们是 ready-to-deploy 的插件，可以直接在 Claude Cowork/Code 中使用，或作为 Managed Agents 的 cookbook。配合 Claude 与 Microsoft 365 的深度整合（Excel、PowerPoint、Word，Outlook 即将加入），agent 可以在实际办公环境中端到端工作。

数据合作伙伴的扩展同样值得关注——新增 8 个连接器（Dun & Bradstreet、IBISWorld、Third Bridge 等）和 Moody's MCP 应用（覆盖 6 亿+ 企业数据）。这意味着 agent 不只是能写文档，还能直接访问权威的市场和信用数据来支撑决策。

§ 02

Services co.自建服务公司：需求超过了合作伙伴的交付能力

5 月 4 日的第二个公告更具战略意义。Anthropic 联合 Blackstone、Hellman & Friedman、Goldman Sachs（另加 General Atlantic、Apollo、Sequoia 等投资方）成立了一家新的 AI 服务公司，专注于帮中型企业将 Claude 整合进核心业务。↗ News

CFO Krishna Rao 给出了直接理由："Enterprise demand for Claude is significantly outpacing any single delivery model."——翻译过来就是：合作伙伴（Accenture、Deloitte、PwC）的交付能力已经跟不上需求增长。

目标客户精确定位在中型企业（社区银行、制造商、区域医疗系统）——这些组织有 AI 需求但缺乏内部技术团队来部署前沿方案。Anthropic 的 Applied AI 工程师将直接驻场工作。

"Enterprise demand for Claude is significantly outpacing any single delivery model."

§ 03

Three paths.三家模型公司的不同战略路径

把 Anthropic 的选择放在竞争格局中看，三家头部模型公司走向了截然不同的方向：

OpenAI → 消费端产品：ChatGPT、Codex CLI、DALL·E、Sora——面向个人和开发者，走流量和订阅。

Google/DeepMind → 基础设施：TPU、Vertex AI、Gemini API——深度绑定 GCP，走云计算捆绑。

Anthropic → 垂直行业交付：金融 agent 模板、NEC 行业方案、中型企业服务公司——直接走进客户的业务流程。

Anthropic 的路径风险更高但锁定更深——一旦 Claude 嵌入了客户的 KYC 流程或月末结账流程，迁移成本不只是 API 切换，而是整个业务流程的重建。这和 Linear 上一期讲的"连接锁定"逻辑一致，只是 Anthropic 把它做到了行业级别。

§ 04

Synthesis.对 PM 意味着什么

两条动态串起来的图景：模型公司正在从"横向平台"走向"垂直交付"。

1. 行业模板改变了竞争层次：当 Anthropic 直接提供"Pitchbook 生成 agent"和"KYC 筛查 agent"，竞争对象不只是 OpenAI 和 Google，还有金融行业的垂直 SaaS 公司和系统集成商。PM 如果在做金融行业 AI 产品，需要重新评估——你的竞争对手可能不再是另一家 SaaS，而是模型公司本身。

2. 自建服务公司是"拉力模型"的极致：当需求超过合作伙伴交付能力时，自建是唯一选项。但这也意味着 Anthropic 和自己的合作伙伴（Accenture、Deloitte）之间从纯合作变成了合作 + 竞争关系。PM 在做渠道策略时，这是一个需要持续观察的动态。

3. "嵌入业务流程"是最深的护城河：API 可以被替换，但嵌入月末结账流程的 agent 不行。Anthropic 的战略本质是——通过垂直深度来获得横向规模无法提供的客户锁定。对 PM：如果你的产品也在集成 AI，问自己——你是在 API 层集成（随时可换），还是在业务流程层集成（换不掉）？

底线判断：模型公司做垂直不是"一时兴起"——这是从 API 经济到解决方案经济的结构性转移。PM 需要重新审视自己在 AI 价值链中的位置：你是模型公司的客户、合作伙伴，还是即将被模板替代的中间层？
